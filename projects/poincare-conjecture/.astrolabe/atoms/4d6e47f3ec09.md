Suppose that $\lambda\colon [0,\infty)\to M$ is a minimizing
geodesic ray with initial point $p$. For each $t\ge 0$ we consider
$B_{\lambda,t}(x)=d(\lambda(t),x)-t$. This is a family of functions
satisfying $|B_{\lambda,t}(x)-B_{\lambda,t}(y)|\le d(x,y)$. Since
$\lambda$ is a minimizing geodesic, $B_{\lambda,t}(p)=0$ for all
$t$. It follows that $B_{\lambda,t}(x)\ge -d(x,p)$ for all $x\in M$.
Thus, the family of functions $B_{\lambda,t}$ is pointwise bounded
below. The triangle inequality shows that for each $x\in M$ the
function $B_{\lambda,t}(x)$ is a non-increasing function of $t$.
 It follows that, for
each $x\in M$, $\mathit{lim}_{t\rightarrow \infty} B_{\lambda,t}(x)$
exists. We denote this limit by $B_\lambda(x)$. This is the *Busemann function* for $\lambda$.
