We say that $t$ is a *regular time* if there is $\epsilon>0$ and
a diffeomorphism $M_{t}\times (t-\epsilon,t+\epsilon)\to \mathbf{t}^{-1}((t-\epsilon,t+\epsilon))$ compatible with time
and the vector field. A time is *singular* if it is not regular.
Notice that if all times are regular, then space-time is a product
$M_{t}\times I$ with $\mathbf{t}$ and $\chi$ coming from the second
factor. If the image $\mathbf{t}({\mathcal M})$ is an interval $I$
bounded below, then the *initial time* for the flow is the
greatest lower bound for $I$. If $I$ includes $(-\infty,A]$ for some
$A$, then the initial time for the generalized Ricci flow is
$-\infty$.
