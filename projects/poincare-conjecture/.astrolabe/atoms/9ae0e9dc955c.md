There is a smooth function $h(w,t)$ defined for $w\ge 0$ so that
$f(r,t)=rh(r^2,t)$. In particular, $h(r^2,t)$ defines a smooth
function on all of $\Ar^n$. Clearly, $h(w,t)>0$ for all $w\ge 0$ and
all $t$.
