We set ${\mathcal U}_x\subset {\mathcal M}$ equal to $ {\mathcal L}\mathit{exp}_x(\widetilde{\mathcal
U}_x)$. We call this subset of ${\mathcal M}$ the *injectivity
domain (of $x$)*.
 For any
$\tau>\tau_1$ we set ${\mathcal U}_x(\tau)={\mathcal U}_x\cap
M_{T-\tau}$.
