# Poincaré Conjecture Challenge

A public, open effort to build the Poincaré Conjecture — and the geometry and
topology behind it — into a living, machine-verified textbook anyone can learn
from, contribute to, reuse, and build on.

Every definition, theorem, and proof is a node in one knowledge graph, shared
between a **natural-language** exposition (`source: tex`) and its **formal
verification** in Lean (`source: lean`), linked by cross-source edges. You can
read it like a book, follow the formalization line by line, and see exactly what
is proven and what is still open.

This project is just getting started — the blueprint and first statements are
being set up.

## Contributing

Pick an open statement and formalize it, transcribe one that is still missing,
review a proof, or improve a link. Anything that lands is shared and reusable by
the next person.
