# Event Log

Dated records of significant project events: what happened, what problem it posed, which workflows were designed in response, and who decided what. One folder per event, named `yyyy-mm-dd-<slug>/`, each with a `README.md` entry point.

Documents inside an event folder may later be promoted to permanent `docs/` top-level status once they prove general beyond the originating event; the log entry keeps a pointer when that happens.
