title: immersion; embedding; submanifold
---
Let $M^m,N^n$ be differentiable manifolds. A differentiable $\varphi:M\to N$ is an
*immersion* if $d\varphi_p:T_pM\to T_{\varphi(p)}N$ is injective for all $p\in M$.
If in addition $\varphi$ is a homeomorphism onto $\varphi(M)\subset N$ (subspace
topology), $\varphi$ is an *embedding*. If $M\subset N$ and the inclusion
$i:M\subset N$ is an embedding, $M$ is a *submanifold* of $N$. If $\varphi:M^m\to
N^n$ is an immersion then $m\le n$; the difference $n-m$ is the *codimension*.
